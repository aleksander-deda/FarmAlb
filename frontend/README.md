# Ardhja — Frontend

Next.js application. Coming in the next phase.

## Planned stack

- Next.js 14 (App Router)
- Tailwind CSS
- shadcn/ui
- React Query (server state)
- Zustand (client state)
- Mapbox GL (interactive map)

## Dev setup (once scaffolded)

```bash
cd frontend
npm install
npm run dev     # http://localhost:3000
```
